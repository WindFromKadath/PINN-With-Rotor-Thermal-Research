# 科研项目协作规则

- 接手先确认用户当前问题，读取 README.md、相关 hypotheses.csv 与 experiments.csv 行，再检查有关原文、代码、配置及原始结果。历史总结中的解释要回查依据。
- 用户要求和已采纳设计确定研究目标；当前实现说明计算过程；原始资料和实验结果支撑具体判断。来源矛盾时注明各自版本与适用范围。
- 作者视角记录作者自己的研究理解与疑点。可对照原始证据指出错误和缺口，由作者理解后回写；实验完成或复核通过不能证明作者已经理解研究链。
- 关键路线改变时说明依据变化、选择和后续验证。存在作者学习目标时，围绕一个预测、对照或异常检查理解，保留作者自己的判断过程。
- 区分探索实验和验证实验。验证实验先确定比较对象、评价与预算；看过结果后改变方案或指标时，登记新实验及改变原因。
- 按独立 run_id 保存原始输出和配置，不覆盖或筛掉失败及负结果。保留代码版本、数据版本、环境和随机种子（适用时）。
- 正确性检查针对计算与实现；实验结果用于检验假设。不得修改数据划分、预算、基线或指标来迎合预期而不记录变更。
- `completed` 表示实验执行完成，支持程度另在假设表中记录；支持、未获支持及无法区分都注明范围与证据。引用不能核实时标为待核实。
- AI 的解释和建议由证据约束，重要研究结论由负责人确认。已有解释影响本轮方案时回查原始结果；可复现仍需考虑偏差和替代解释。
- 在既定预算与范围内自行执行和修复普通错误；研究目标、关键设计或预算变化时，先说明影响，由用户决定。
- 更新已有假设和实验索引，在对话中交接。独立论文或实验报告有明确用途时才新建 Markdown，并从入口链接。
- 多个执行者同时工作时，指定一位汇总者更新共享索引，分别使用独立 run_id 保存产物。
- 结案报告：实验编号、实际设置与版本、原始结果位置、对假设的有限判断、失败与局限、下一步验证。

- 提交前核查完整暂存内容与署名，发布前另核查拟发布历史及附件；未核查材料保持待核验，不把实验完成当作公开批准。

## 本项目实现约定

- 原始反问题项目（本地归档） 仅作只读来源，不写入、移动或覆盖其数据和代码。
- 同级 `InversePINN_Again`、`PINN_Inverse_fin_pls` 等历史目录同样只读。已找到裸 `.pth` 权重和温度表，历史复用工具保留原变换并单独记录；不得直接将其当作新库的检查点或将旧数据上的指标写成新耦合模型精度。旧报告样本总体与目前文件不一致。用户已明确无需精确复现旧指标，当前验收是代码和模型可用；旧报告差异仅保留作背景，不阻塞本轮完成。
- 首版是已知厚度先验下的温度重建与全长接触参考实现。未知厚度联合反演、不同初温或三维接触模型属于后续研究，不能静默改写当前假设。
- Python 3.12.14，使用 uv、独立 `.venv` 和项目本地 `.cache/uv`。CPU/cu130 extras 互斥；运行、测试与环境安装选择一致的 extra，不修改全局缓存或 Git 配置。
- 数据统一 SI：m、rad、s、K；厚度必须正，肋编号必须整数。列映射和单位显式设置，预处理只写新文件，永不覆盖原始输入。
- 按空间位置分组，所有时刻同一分区；观测损失只用 train。不得为了改善指标重划空间分组。L2 分母为绝对 Kelvin 温度。
- 统一圆环 `[r/R,theta,t/t_max]`、肋 `[s/R,rib_id,t/t_max]`。模块导入不加载数据、训练或绘图，保存/重载使用相同网络工厂。
- 厚度参数可冻结，空间输入求导必须保留。修改缩放、物性或扩散方程后运行解析 float64 检查；导数/残差相对误差目标 1e-6。
- 接触的正功率从圆环流向肋；两侧独立半厚度等效热阻。全长投影与温度平均共用面积归一化核，弧长求积权重不可省略。修改耦合后验证交换功率归一化不平衡小于 1e-6。
- 每轮三域共享显式 CouplingState，不通过全局变量传递热流。离散功率守恒不证明有限轮次固定点收敛，也不证明真实精度。
- demo 合成标签只是流程函数，并非 PDE 真解。科学假设初始为 untested；真实 COMSOL 数据、基线比较和精度保持待验证，历史 RMSE 6.0609 K 不作验收承诺。
- 保存独立运行编号、源码/输入/配置/权重哈希、环境和种子；失败和负结果保留。沿用 hypotheses.csv/experiments.csv 原有列，作者视角由作者维护，不增设平行进度报告。
- 日常检查：`uv --cache-dir .cache/uv run --locked --extra cpu pytest` 与 `ruff check .`。CUDA 验收使用相同 cuda extra；数值记录用 `tools/verify.py` 保存。只运行与变化有关的必要检查。

- 按用户要求，历史优选代码与模型保存在 `local_reference_versions/`，整个目录忽略 Git；本任务不初始化、提交、推送或发布 Git。保留来源只读，不能把“保留最优数个”解释为删除未选原版本。
- 历史模型排序限于已核对定义的完整可比较模型及同一数据总体；保留排除理由和所有候选结果，不称作父目录所有方法的全局最优或独立测试精度。更新保留集使用新目录与独立 run_id，禁止覆盖既有证据。
- 优先使用 `fin_v3_1` 的独立工厂与 `LegacyBundle`，原源码快照用于溯源；加载不依赖原目录。裸历史权重与新检查点继续分开管理，不猜测未保存的厚度尺度或训练源码版本。
