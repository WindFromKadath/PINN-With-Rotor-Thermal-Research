# 反问题路线的证据与推导缺口

## 已有证据的边界

[M0028](notes/M0028.md) 是历史温度误差报告，共 1,074,640 点，总体 RMSE 6.0609 K。它说明某个历史模型在该数据总体上得到这些数值，没有提供未知厚度的恢复误差、唯一性或可辨识性证据。当前参考库的恢复点集与旧报告总体不同，不能把指标差异直接归为算法进步。

[M0016](notes/M0016.md) 是等效导热参数学习的工作流程；[M0204](notes/M0204.md) 则明确说没有完成具体参数反演。现有文本不足以支持“反问题已经求解完成”。四模块迁移完成的含义仍是代码及保留模型可用。

当前可用的历史版本、输入求导和重复加载证据位于 [V004](../verification/records/V004_LEGACY_PORTABLE/metrics.json)。[最终检查](../verification/records/V004_LEGACY_PORTABLE/final_checks.json) 的 `all_usable` 只针对模型可用性。当前合成 demo 标签是流程函数，不是 PDE 真解。

## 待补清单

| 编号 | 缺口 | 已有材料 | 后续所需 |
|---|---|---|---|
| I-G01 | 未知厚度反演的数学定义和可辨识性 | 历史目标与当前已知厚度实现 | 明确未知函数、观测算子、已知边界/物性、唯一性或不可辨识反例；不得把几何监督训练当成反演 |
| I-G02 | 正则化与噪声稳定性 | 正值厚度网络及温度损失 | 正则项含义、噪声级别、参数恢复误差和稳定性；只约束 H>0 不足以保证唯一 |
| I-G03 | 降维等效参数能否跨散热条件复用 | [M0016](notes/M0016.md) 第 6、9 节 | 从三维厚度积分明确被省略项；证明或实验检查等效参数随工况的变化 |
| I-G04 | 厚度平均、接触平均和表面温度的关系 | [M0174](notes/M0174.md) 第 III、VIII、IX 节 | 明确平均测度、表面函数和温度沿厚度的近似误差；K 与 m·K 数据不得混用 |
| I-G05 | 半厚度热阻模型的适用性 | 当前 README；共用薄壳材料 | 指定厚度剖面与两侧边界；与 H/(3k) 版本做独立对照，不能自动合并 |
| I-G06 | 连续功率守恒与耦合收敛 | 当前归一化核和离散恒等式 | 核宽、面积/弧长加密误差及冻结迭代收敛条件；离散求和相等不证明固定点收敛 |
| I-G07 | 真实温度重建的独立验证 | 历史误差报告、迁移重放 | 预先固定空间分组、边界、物性、预算和测试点；保留同位置所有时刻在同分区 |

优先澄清 I-G01 的研究目标，再决定是否启动未知厚度实验。用户当前要求的整理不包含这项新研究。本轮保留 [H001/H002](../../hypotheses.csv) 的待验证状态，没有以文件可运行替代科学判断。

## 与环肋模块的关系

厚度积分、螺旋线和串联热阻材料可以共读；当前两库的端点边界、接触系数、核归一化及温度网络输出变换不同。需要修改时先选择一个版本，不把跨版本差异当成同一条推导链。

参见 厚度降维材料（见本模块模型说明及M0174/M0175整理稿） 和 [本模块来源目录](sources.md)。
