# M0016 · 历史反问题工作流：等效参数辨识的提案边界

来源类型：`implementation_notes`；原件SHA-256：`87a6084993228f1899752540ef94054a9b34a8cae8d5c8e87570ecda61d6a78b`。

阅读范围：全文；等效参数及散热复用建议。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

历史工作流提出先对三维 COMSOL 温度沿轴向平均，再用二维 PINN 学习等效导热参数，并比较等厚环、变厚环与多域肋结构。它是流程建议，没有完整可辨识性、唯一性或误差证明。

文中建议训练时省略散热、预测时恢复真实散热。没有证明被省略的边界能流可以由一个不变的 $`k_{eff}`$ 吸收，也没有说明改变工况后为何还能使用同一参数。这个提案未作为当前已知厚度温度重建的物理前提。

厚度网络拟合几何先验与从温度反演未知厚度是两个任务；目前参考库完成前者及三域温度重建。未知厚度任务仍需要明确观测、未知量、正则化、独立真值和噪声对照。
