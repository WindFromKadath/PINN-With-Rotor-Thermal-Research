# 反问题路线的模型与现有推导

本页把反问题历史目标、目前可用的已知厚度参考实现，以及它借用的降维材料分开整理。本轮没有补写未知厚度反演的证明，也没有改变现有物理代码。

## 历史目标与当前范围

历史流程 [M0016](notes/M0016.md) 介绍了把三维 COMSOL 温度沿轴向平均后，学习二维等效导热系数的想法。相关路线还尝试由温度辨识厚度、使用多域和螺旋肋几何。流程图与建议不是反演成功的证据。

尤其是“训练时去掉散热、预测时重新加入真实散热”的做法，在该文档中是方案建议。没有提供被省略项如何进入 \(k_{eff}\)、新边界下是否保持同一等效参数的证明，不作为当前模型的前提。

降维周报 [M0204](notes/M0204.md) 第 5 张直接说明当时没有实现具体的压缩参数反演。这与当前参考库的范围一致：**已知厚度先验下的上下环与肋温度重建**。首版厚度网络是几何先验；冻结或预训练它不等于从温度识别出了未知厚度。

对照 [当前 README](../../README.md)、[物理残差](../../src/rotor_pinn/physics.py) 和 [耦合状态](../../src/rotor_pinn/coupling.py)。历史 `fin_v3_1` 等模型通过独立兼容加载器重放，不能混作新模型的检查点。

## 三域的参考能量方程

当前库保存的圆环残差，单位为 W/m²：

\[
\rho c(T_j)H_jT_{j,t}
-\frac1r\partial_r(rk(T_j)H_jT_{j,r})
-\frac1{r^2}\partial_\theta(k(T_j)H_jT_{j,\theta})
-H_jQ_j+f_j\ell(T_j)+S_j=0.
\]

肋的残差，单位为 W/m：

\[
\rho c(T_b)A T_{b,t}-\partial_s(k(T_b)A T_{b,s})-AQ_b
+P_{exposed}\ell(T_b)-q'_u-q'_l=0.
\]

\(\ell(T)=h_c(T-T_\infty)+\varepsilon\sigma(T^4-T_\infty^4)\)，这里温度为 K。默认每个环一个暴露端面、肋两侧暴露，肋端绝热；历史环肋文档中的筋端对流/辐射条件属于另一个版本。当前扩散保留温变 k 与厚度 H 的空间导数。

以上是当前参考实现的整理，不能追溯为早期流程图已经完整证明的方程。共同的物理背景可读 [M0174](notes/M0174.md) 与 [M0175](notes/M0175.md)，但它们存在薄壳、厚度平均和几何度规的推导缺口，见环肋模块。

## 几何与尺度

当前参考几何沿用主 README：

\[
\theta_i(r)=1.2209+6.4105(r-0.123)+2\pi i/13,
\qquad
s(r)=\int_{0.123}^{r}\sqrt{1+(6.4105\xi)^2}\,d\xi.
\]

肋覆盖 \(r\in[0.123,0.225]\) m，13 根，长度约 0.153349212 m；上下环内径分别 0.084/0.103 m，外径 0.225 m。宽 0.016 m，高 0.0094 m。

网络输入分别为 \([r/R,\theta,t/t_{max}]\) 和 \([s/R,rib\_id,t/t_{max}]\)。残差计算把坐标导数换回 SI；温度输出为 \(T=T_\infty+T_su\)，硬初值只支持初始均匀环境温度。厚度使用正值输出变换，冻结参数时保留输入导数。

本库的面积平均与肋长求积采用固定几何。现有资料没有证明该几何及厚度数据足以代表全部三维接触细节。

## 全长接触与离散功率

当前参考实现采用半厚度串联热阻：

\[
R_{eff,j}=\frac{\overline H_j}{2k(\overline T_j)}+
\frac{h_b}{2k(T_b)}+R_{contact,j},\qquad
q'_j=\frac{w}{R_{eff,j}}(\overline T_j-T_b).
\]

\(R_{eff}\) 的单位为 m² K/W，\(q'\) 为 W/m，正方向为环流向肋。默认界面热阻为零，仍保留降维半厚度热阻。这与环肋主线的 \(H/(3k)\) 版本有明确差异。

现有 README 给出面积归一化核的离散关系：

\[
\overline T_a=\sum_i\omega_iK_{ia}T_i,\qquad
S_i=\sum_aK_{ia}\lambda_a q'_a,\qquad
\sum_i\omega_iS_i=\sum_a\lambda_aq'_a.
\]

这里 \(\omega_i\) 是圆环物理面积权重，\(\lambda_a\) 是弧长权重。温度平均与功率投影使用同一个归一化核。该式是**当前离散求积上的代数关系**，不证明连续模型、未知参数反演或有限轮耦合达到正确解。它是新参考实现中的关系，不能作为旧版本已证明守恒的证据。

每轮显式 `CouplingState` 固定交换功率后交替训练；默认松弛系数 0.5。有限训练后的状态是滞后功率，没有固定点收敛证明。
