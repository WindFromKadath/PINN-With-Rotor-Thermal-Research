# M0063 · 批投影误差诊断：批集合依赖与未验证解释

来源类型：`implementation_notes`；原件SHA-256：`01a95108b258e322f9ca4092cee71ef7cc60eaa74d6b2f91991bb78cd4521169`。

阅读范围：全文；批均值、detach及梯度累积建议。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

原诊断讨论逐批扣除轴向均值时，不同批次得到不同平移量，拼接预测会出现跳跃。这个现象支持保持固定参考系的部署方案。

对于某个固定批 $`B`$，$`c_B=\sum r_i u_{z,i}/\sum r_i`$，若代码使用detach，输入导数把c_B视为常数；只依赖应变/导数的轴向刚体平移不改变该批PDE。原报告将批间变化解释为必然增加PDE梯度，并建议梯度累积形成全局均值，这些解释未通过完整Jacobian或对照证明。

梯度累积不会自动将各批投影替换为全局投影。需要分别检查值损失、参考点约束、采样测度、是否detach以及批内外的求导对象。当前推理保存一次全局轴向对齐常数，不在每个查询批上重新估计。
