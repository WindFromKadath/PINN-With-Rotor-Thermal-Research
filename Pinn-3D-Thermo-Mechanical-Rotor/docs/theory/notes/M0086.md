# M0086 · 历史瞬态热力综合报告：主线与有限数值证据

来源类型：`historical_metrics`；原件SHA-256：`cb5fc5768a5852e127dd929ecb10105f5e16aece3fc90d7035baadf5d61f243a`。

阅读范围：全文；数值对比和经验结论。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

报告描述STL采样→无量纲化→Heat PINN→冻结热网的Mechanical PINN流水线。热网输入[r*,z*,t*,sinθ,cosθ]、5×64 Tanh、单输出，17089参数；力网输入[r*,z*,t*]、5×128 Tanh、两输出，66818参数。

报告记录HeatPINNCheck点集244565点，MAE1.30 K、RMSE1.81 K；ElsPINNCheck点集978260点的逐时间平均RMSE1.44e-3 mm、平均MAE7.75e-4 mm、平均RelL2约0.030。它们属于历史报告的评价器、数据总体与参考系，未在本轮文本接入中全量复算。t=0的近零真值分母尤其需要单独解释。

报告配置轴向包围盒较大，但已迁移主线STL实际只含下层薄壳，不能据此称全转子训练。其他表面的绝热文字也需与实际加载的边界类别核对。吞吐量是特定GPU/批量/测时方案，不能推广为本机性能承诺。

MLP对比、周向采样和相关分析提供有限样本的数值观察，不能证明力学约束吸收了全部温度误差，也不证明算子泛化或准静态近似在所有时间尺度上成立。
