# M0060 · 3D热力公式汇总：无量纲步骤与版本校准

来源类型：`formula_summary`；原件SHA-256：`6a4496e5d5ad57ea91ab02687c03208c8acc56bef11ccc850fb7b876458015a9`。

阅读范围：全文；尺度、方程、角度导数、配置差异。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

原公式汇总从柱坐标导热、轴对称应变、本构与静力平衡出发，并列出sin/cos角度链式求导。存在多套温差/位移尺度和数值常量；这里结合当前主线记录原有替换关系，不合并不同profile。

定义 $r=Lr^*$、$z=Lz^*$、$t=\tau t^*$、$T=T_0+\Delta T u$，故 $T_t=(\Delta T/\tau)u_{t^*}$、$T_r=(\Delta T/L)u_{r^*}$。常物性原方程除去 $\rho c_p\Delta T/\tau$ 后为：

\[u_{t^*}=Fo[u_{r^*r^*}+u_{r^*}/r^*+u_{\theta\theta}/(r^*)^2+u_{z^*z^*}],\quad Fo=k\tau/(\rho c_pL^2).\]

热网令 $a=\sin\theta,b=\cos\theta$。原文给出链式法则，可整理为：

\[u_\theta=b u_a-a u_b,\qquad u_{\theta\theta}=b^2u_{aa}+a^2u_{bb}-2ab u_{ab}-a u_a-b u_b.\]

主线取L=0.225m、ΔT=300K、τ=200s、ρ=7870、cp=440、k=76.2，已有算术核对得到Fo=0.0869345723。位移尺度 $U=\alpha\Delta TL=8.235\times10^{-4}$ m，应力尺度 $\Sigma=E\alpha\Delta T=732$ MPa。论文中的0.104和73.2MPa不能归给同一组参数。

主线以 $u/U$ 为位移变量，$\lambda^*=\lambda/E$、$\mu^*=\mu/E$、$\beta^*=(3\lambda+2\mu)/E$。汇总文中的u/L及另一套Lamé数字属于其他约定。来源舍入值λ*=0.5354、μ*=0.3876、β*=2.3810被兼容实现保留，3λ*+2μ*=2.3814不是完全相同。

角度链式和尺度的实现检查不证明长预算收敛、轴对称温度桥或材料适用范围。
