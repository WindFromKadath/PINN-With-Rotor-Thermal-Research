# 贡献指南

[English](CONTRIBUTING.md) | 简体中文

先读 README.zh-CN.md、MAINTAINER.md、AGENTS.md 和有关假设/实验行。当前参考库已实现；安装与基础检查使用：

```powershell
uv sync --locked --extra cpu
uv run --locked --extra cpu pytest -q
```

每次使用新 run_id，保留配置、数据、环境、原始结果及失败。研究设计、物理公式、参考系或评价口径改变时登记新实验；不要覆盖旧结果或用短训练宣布精度获证。完整预算配置未经首轮验收，不自行扩展为长训练。

修改读者入口时同步中英文 README 与贡献指南。维护记录用中文，作者研究理解由作者维护。通过当前协作对话或维护记录提供版本、最小复现和预期行为，不附私人路径、凭据或受限数据。

代码和必要研究文本按本项目提交范围准备；数据、权重与原始归档仍本地保存。不自动提交、推送、发布或更改 Git 配置。使用有合法权限的资料并记录来源；第三方数据与权重的再发布权限尚未确认。

真实数据demo需要[克隆运行说明](docs/running_from_clone.md)中的本地资产。
