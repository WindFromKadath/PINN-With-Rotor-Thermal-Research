# 科研项目协作规则

- 接手先确认用户当前问题，读取 MAINTAINER.md、README.md 或 README.zh-CN.md、相关 hypotheses.csv 与 experiments.csv 行，再检查有关原文、代码、配置及原始结果。历史总结中的解释要回查依据。
- 双语 README 面向读者说明方法归属、数据获取、复现、证据与限制；MAINTAINER.md 保存本轮设计、作者理解与已采纳取舍。公开 README 与贡献指南同步更新中文／English，命令、版本、指标单位、引用、限制和许可一致；维护记录是否公开按内容检查。
- 用户要求和已采纳设计确定研究目标；当前实现说明计算过程；原始资料和实验结果支撑具体判断。来源矛盾时注明各自版本与适用范围。
- 作者视角记录作者自己的研究理解与疑点。可对照原始证据指出错误和缺口，由作者理解后回写；实验完成或复核通过不能证明作者已经理解研究链。
- 关键路线改变时说明依据变化、选择和后续验证。存在作者学习目标时，围绕一个预测、对照或异常检查理解，保留作者自己的判断过程。
- 区分探索实验和验证实验。验证实验先确定比较对象、评价与预算；看过结果后改变方案或指标时，登记新实验及改变原因。
- 按独立 run_id 保存原始输出和配置，不覆盖或筛掉失败及负结果。保留代码版本、数据版本、环境和随机种子（适用时）。
- 正确性检查针对计算与实现；实验结果用于检验假设。不得修改数据划分、预算、基线或指标来迎合预期而不记录变更。
- `completed` 表示实验执行完成，支持程度另在假设表中记录；支持、未获支持及无法区分都注明范围与证据。引用不能核实时标为待核实。
- AI 的解释和建议由证据约束，重要研究结论由负责人确认。已有解释影响本轮方案时回查原始结果；可复现仍需考虑偏差和替代解释。
- 在既定预算与范围内自行执行和修复普通错误；研究目标、关键设计或预算变化时，先说明影响，由用户决定。
- 更新已有假设和实验索引，在对话中交接。独立论文或实验报告有明确用途时才新建 Markdown，并从入口链接。
- 多个执行者同时工作时，指定一位汇总者更新共享索引，分别使用独立 run_id 保存产物。
- 结案报告：实验编号、实际设置与版本、原始结果位置、对假设的有限判断、失败与局限、下一步验证。

## 隐私与提交

- 区分公开方法、可公开合成数据、受限制的原始数据和原始会话；引用文献不自动获得再发布原文、附件或第三方数据的权限。
- 提交前核查完整暂存内容与署名，发布前另核查拟发布历史及附件；未核查材料保持待核验，不把实验完成当作公开批准。
- 需要自动检查时按目标项目规则配置并验证，保留已有团队 Hook；本模板不自动安装工具或更改 Git 设置。
- 记录范围、版本和人工核查结果；私人规则和原始审计材料留在合适的本地位置，检查输出不暴露匹配原文。

## 本项目约束

- 当前代码/模型迁移已完成；先读双语 README、MAINTAINER、experiments.csv 和 docs/verification/README.md。完整预算未执行；不把历史或短训完成写成科学假设成立。
- 完整来源包含内层源码快照及同级历史数据/权重。原来源只读；本轮代码、数据和参考包应能独立使用。
- 主线热学为 3D 瞬态，力学为轴对称热弹性单向耦合；稳态 X-PINN、正式热学与主线分别绑定 profile，不混用参考尺度或模型。
- 热网冻结权重但保留输入导数；PDE 温度桥不使用 no_grad/detach。源界面导数先计算，再按来源策略停止梯度。
- Python 3.13.14 与项目独立 uv 环境；显式依赖、互斥 cpu/cuda extras、项目 .cache/uv 和 uv.lock。环境未安装前不声明可运行。
- 配置数据路径相对配置文件，物理参数从 profile 提取；独立 run_id，拒绝覆盖，失败保留，不把缺数据 dry-run 标为训练 completed。
- 模型格式、网络、变换、尺度、温度桥与对齐策略一起保存；严格加载及哈希核验。历史原表在本地归档，不将历史指标视为本轮复算。
- 首轮以代码/模型可用及短流程完成验收，不要求完整精度复现。科研假设状态由负责人按证据判断，不自动改写。
- 保留精选历史版本与完整来源索引。大数据、权重、快照和产物默认忽略，不上传 Git，不自动提交、推送、安装 Hook 或更改 Git 配置。
- 维护记录用中文；读者 README 和贡献指南中英文同步；不嵌入真实姓名、机器绝对路径或凭据。作者理解由作者维护。

## 仓库内资料接入

必要理论、来源编号/哈希与有限验收摘要已随代码保存在docs中。无本地原件时先读docs/theory与docs/verification，不把缺少原始数据的历史重放标为通过；需要核验新的科学主张时再恢复对应原件与产物。代码和必要文本按本项目的提交范围准备，数据、模型、原件与完整日志继续本地保留；不自动提交或推送。
