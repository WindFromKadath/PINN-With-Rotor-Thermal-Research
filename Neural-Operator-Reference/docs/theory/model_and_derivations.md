# 算子学习的模型与现有推导

本页整理既有研究材料，供阅读和修改参考库时对照。来源中的公式、现有实现及未完成的研究目标分别注明。本轮没有补写新的证明，也没有更改物理代码。

## 研究问题与路线

早期路线希望学习“热源、边界参数或初始函数 → 温度场”的映射。DeepONet 使用 Branch 表示输入函数的采样值，Trunk 表示查询坐标；FNO 在输出场的网格上学习映射。固定一个工况的 PINN 主要逼近该工况的解函数。不能仅凭模型名把单工况预测视为已验证的参数或几何泛化。

阅读材料 [M0183](notes/M0183.md) 的段落 1–20，以及 [M0182](notes/M0182.md) 的幻灯片 2–5。前者给出概念和网络组成，后者给出热源标签、显式时间离散和网络输入。两者是学习与实现笔记，没有完整的算子逼近定理证明。

参考库保留 1D FNO/PINO、笛卡尔 2D DeepONet/PI-DeepONet，以及极坐标圆环 PINO/PIDON/PINN。圆环稳态解析基准与瞬态学习任务应分别阅读。相关入口见 [主 README](../../README.md) 和 [问题定义](../../src/heatops/problems/annulus.py)。

## 圆环方程与单位

常物性、无体热源的圆环模型为：

\[
\rho c_p T_t=k\left(T_{rr}+\frac1rT_r+\frac1{r^2}T_{\theta\theta}\right).
\]

稳态时左侧为零。内壁规定沿正径向进入圆环的热流，外壁向环境对流：

\[
-kT_r(R_i)=q_{in},\qquad
-kT_r(R_o)=h\,[T(R_o)-T_\infty].
\]

这里的内壁表达使用径向导数；它不是在内、外壁都采用同一个外法向的写法。若改用外法向，必须重新检查符号。

[M0013](notes/M0013.md) 第 1–2 节给出这些公式。当前 `AnnulusParams` 沿用摄氏温度，默认环境 20 °C；COMSOL 导入需显式换单位。本模块的温差无量纲化可以使用 °C 差值，其他模块中的辐射四次方项必须使用 K。不要直接混接这两种温度契约。

## 无量纲化的两个时间尺度

原报告及当前问题模块定义：

\[
r^*=r/R_o,\qquad u=(T-T_\infty)/T_s,\qquad
T_s=q_{base}R_o/k,\qquad Bi=hR_o/k.
\]

瞬态极坐标配置使用观测时长 \(t^*=t/t_{max}\)，PDE 保留 \(Fo=kt_{max}/(\rho c_pR_o^2)\)。解析问题对象还提供扩散时间 \(R_o^2\rho c_p/k\)；使用这个时间尺度才会令 Fo 为 1。两种定义不能在复用配置时悄悄互换。对照 [极坐标配置](../../configs/pino_annulus_polar.yaml) 与 `AnnulusParams.t_scale`。

内壁无量纲热流为 \(-u_{r^*}=q_{in}/q_{base}\)，外壁为 \(-u_{r^*}=Bi\,u\)。原报告的单位热流案例取 \(q_{in}=q_{base}\)。

## 已有解析解步骤

[M0013](notes/M0013.md) 第 6 节列出轴对称稳态解：

\[
u(r^*)=C_1\ln r^*+C_2,\qquad
C_1=-q_i^*R_i^*,\qquad C_2=-C_1/Bi.
\]

当前 `analytical_steady_state` 与其无量纲对应函数保存同一基准。原报告给出了结果及边界代入说明，未展开从径向常微分方程到积分常数的全部步骤。该解析解适用于轴对称、常物性、无体热源的稳态圆环，不适用于任意热源、瞬态或复杂几何。

本轮按原报告自身参数作算术核对：\(R_i=0.05\) m、\(R_o=0.147\) m、\(q=10^5\) W/m²、\(k=50\)、\(h=10\)、环境 20 °C，其公式给出的外壁约为 **3421.36 °C**，内壁约为 **3529.20 °C**。报告写出的约 39 °C 和 447 °C 与上述公式及参数不一致。这是内部一致性核对，不能将如此高温下的常物性外推解释为可用的真实材料预测。

## 物理损失与求导对象

[M0182](notes/M0182.md) 与 [M0189](notes/M0189.md) 介绍了数据、PDE、初值和 Robin 损失，以及 Adam 后接 L-BFGS 的训练方式。幻灯片中部分公式是图片，抽取文本不足以还原。

当前实现中的一个重要区分是：对逐点坐标网络，可以对查询坐标使用 autograd；FNO 输出是非局部场映射，当前参考库对**输出温度场**使用可微有限差分。输入某个网格点的导数不等于该点输出温度的空间导数。角度端点的一阶导数分别采用两端单侧差分；端点值相等与端点斜率相等是不同的检查。

现有说明没有给出 FNO 网格加密收敛、有限差分截断误差向训练误差传递、损失权重最优性或训练全局收敛的证明。FFT 特征也不能自动证明非周期径向边界得到满足。
