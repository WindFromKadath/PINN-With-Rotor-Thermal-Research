第3–4张采用空间中心差分、时间显式Euler及Robin边界，提出需满足CFL，但关键公式为图像，文本未完整提取稳定性证明。当前参考库的C-N标签求解器是另一种离散方法，应按代码分别验证。

PI-DeepONet将监督损失扩展为PDE、初值、边界损失，需要明确输入函数分布、配点和损失权重。报告中的训练指标与引用论文的误差对比是各自案例，不是当前转子问题的普遍性能结论。多保真和门控讨论属于学习扩展，不代表本轮全部实现。
