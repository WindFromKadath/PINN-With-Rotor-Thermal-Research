# M0013 · 圆环 PINO 数学分析报告：解析基准与原报告矛盾

来源类型：`analysis_report`；原件SHA-256：`a78d94ec50f675c2c2fcd7062942c91734f3d412022bb8437ebd6ff51d9c01a6`。

阅读范围：全文；圆环公式与参数数值核对。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

原报告给出稳态无源圆环、内边界向外热流和外边界对流。参数为 $R_i=0.05$ m、$R_o=0.147$ m、$k=50$ W/(m·K)、$h=10$ W/(m²·K)、$q_i=10^5$ W/m²、$T_\infty=20$ °C。

\[\frac1r\partial_r(rT_r)+\frac1{r^2}T_{\theta\theta}=0,\qquad -kT_r(R_i)=q_i,\quad -kT_r(R_o)=h(T(R_o)-T_\infty).\]

原文列出 $r^*=r/R_o$、$T_s=q_{base}R_o/k$、$u=(T-T_\infty)/T_s$、$Bi=hR_o/k$、$q_i^*=q_i/q_{base}$，轴对称解为：

\[u(r^*)=C_1\ln r^*+C_2,\qquad C_1=-q_i^*R_i^*,\qquad C_2=-C_1/Bi.\]

原文同时声称内外温度约447/39 °C。已有算术复核将同一参数代入，得到外温3421.360544 °C、内温3529.201502 °C，原文数字不一致。此复核只检查常物性公式，不预测钢在该高温下的实际行为。

原报告的“64×64足够”“数学正确”“能量误差小于1%”属于报告主张，缺少绑定权重、点集和收敛研究；FNO的FFT结构也不自动保证独立周期端点导数匹配。当前输出场差分与解析场检查分别见本模块模型说明及测试。
