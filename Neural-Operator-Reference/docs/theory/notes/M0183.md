# M0183 · DeepONet学习笔记：函数、算子与Branch/Trunk

来源类型：`study_notes`；原件SHA-256：`b365821f3662b079e41debda01576590adb4274db81177e4bf13fbf2ef90688f`。

阅读范围：全文文字及OMML；概念笔记。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

笔记区分数到数的函数逼近与函数到函数的算子映射。输入函数由传感点值u(x1)…u(xm)表示；Branch编码这些函数值，Trunk编码查询点y，两网络输出点乘得到G(u)(y)。

GRF用于抽取输入函数，输出标签来自数值ODE/PDE解。传感器离散化本身也有误差，函数数量与查询点数量构成训练样本。

笔记只记录架构与学习方向，没有给出算子逼近定理的紧性、连续性、传感器充分性或误差界证明。FNO/WNO/LNO/GKN的列举不是这些方法已经通过当前数据检验的证据。
