# M0038 · 旧加热模型的五阶段降维推导与未闭合步骤

来源类型：`derivation_with_gaps`；原件SHA-256：`6af471df7f45fd43a782550692aa3ede20186e80e289ad0620b2f90b977e38b3`。

阅读范围：全文；五阶段推导，重点Leibniz与H/(3k)。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

原文的步骤依次为轴向积分、表面法向与路径修正、厚度热阻、面线耦合、边界功率。以下按原有步骤整理，保留假设与疑点。

静态上下限 $`z\in[\zeta_b,\zeta_t]`$、$`H=\zeta_t-\zeta_b`$、$`\bar T=H^{-1}\int T dz`$。原文从 $`\rho c_pT_t=\nabla\cdot(k\nabla T)+\dot q`$ 出发，列出：

```math
\int_{\zeta_b}^{\zeta_t}\nabla_\perp\cdot(k\nabla_\perp T)dz=\nabla_\perp\cdot\int_{\zeta_b}^{\zeta_t}k\nabla_\perp Tdz-[k\nabla_\perp T\cdot\nabla_\perp\zeta_t]+[k\nabla_\perp T\cdot\nabla_\perp\zeta_b].
```

轴向扩散积分给出 $`[kT_z]_b^t`$。将积分内热流近似为 $`kH\nabla_\perp\bar T`$ 是闭合假设，非精确恒等式。

表面面积因子 $`\gamma=\sqrt{1+|\nabla_\perp\zeta|^2}`$，外法向通量 $`-k\nabla T\cdot n=Q_{out}`$。原文由 $`dL=dr\sqrt{1+m^2}`$ 与投影推得 $`\Lambda=\cos^2\vartheta=(1+m^2)^{-1}`$。上下表面的外法向不同；原文中法向展开的正负需要统一，单方向路径论证不能直接证明一般二维曲面的标量扩散。

厚度方向原文列出 $`kT''+\dot q=0`$，$`T(z)=-\dot qz^2/(2k)+C_1z+C_2`$，随后写 $`\bar T-T_s=q_sH/(3k)+\dot qH^2/(8k)+\cdots`$。另一端边界、常数与省略项未闭合，不能据此认定1/3总比1/2准确。原版耦合使用 $`R_{total}=H/(3k)+H_M/(2k)`$。

螺旋线 $`\theta_i(r)=\theta_{0,i}+\psi(r-R_{rib,in})`$，原文的弧长关系为：

```math
ds=\sqrt{1+(r\psi)^2}dr,\qquad A=wH_M,\qquad q'=wq_{interface},\qquad D_s=\partial_s(kA T_s).
```

面通量乘宽度得到线功率，是单位协调；完整面线积分相等还需要一致的接触带与求积映射。

径向边界在厚度积分近似下写成 $`-kH\Lambda\bar T_r=H[h(\bar T-T_\infty)+\epsilon\sigma(\bar T^4-T_\infty^4)]`$，内外法向分别处理。温变物性与辐射平均的闭合误差未证明。原文“严格闭环”的措辞不作为验证结论。
