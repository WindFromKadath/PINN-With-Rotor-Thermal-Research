# M0053 · 串联接触热阻与无量纲Bi的既有步骤

来源类型：`derivation_with_gaps`；原件SHA-256：`621bc7ea5fd9783effbef9b23be117c5535d95688a693c126ab0e4bbab829300`。

阅读范围：全文；串联热阻及无量纲化。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

原文采用厚度方向一维串联模型：圆环中面到接触面、界面接触、肋面到肋中面。

```math
R_{ring}=H_{ring}/(2k_{ring}),\quad R_{int}=1/h_{int},\quad R_{rib}=H_{rib}/(2k_{rib}),\quad h_{eff}=(R_{ring}+R_{int}+R_{rib})^{-1}.
```

共同温差驱动 $`q''=h_{eff}(\bar T_{ring}-T_{rib})`$，再乘接触宽度w得到W/m线功率。以 $`L`$、$`k_{ref}`$、$`H^*=H/L`$、$`\kappa=k/k_{ref}`$、$`Bi_{int}=h_{int}L/k_{ref}`$ 表示：

```math
Bi_{eff}=\left[H_{ring}^*/(2\kappa_{ring})+1/Bi_{int}+H_{rib}^*/(2\kappa_{rib})\right]^{-1}.
```

这是原文的一维热阻假设；推荐的界面Bi参数只是建议，未绑定测量或辨识结果。它与旧加热的H/(3k)版本不同，当前反问题参考实现保留半厚度版，环肋主线保留来源的三分之一版。
