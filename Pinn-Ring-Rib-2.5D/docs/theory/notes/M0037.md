# M0037 · 热流平衡建议：从温度快照到通量快照

阅读范围：全文；热流快照和未获证明的防漂移主张。这是既有材料的整理稿，保留公式与有限判断，不新增证明；原件和历史脚本不是本页的运行依赖。

这份建议讨论多域交替训练中的共同温度漂移，提出记录肋侧热流、映射回圆环并约束 $L_{flux}=\|q_{ring}-q_{rib,saved}\|^2$，其中界面热流由等效换热系数与温差计算。

这是机制建议，没有给出每轮训练误差界、固定点收敛条件或连续能量守恒证明。共同温度偏移是否被PDE、空气散热、初值与数据锚点约束，应检查完整损失，不能只根据接触温差判断欠约束。现参考库保存每次运行独立的快照状态，保留来源更新顺序与查询方式。
