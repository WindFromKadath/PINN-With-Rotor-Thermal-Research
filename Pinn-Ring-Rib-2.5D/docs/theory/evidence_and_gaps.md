# 环肋 2.5D 的证据与推导缺口

现有材料中，“推导”“修改建议”“实验总结”相互混杂。本轮按内容组织，保留原句和版本供回查；没有把“严格”“最准确”“数学极限”等历史评价直接采纳为研究结论。

## 推导完整程度

| 来源与位置 | 能定位的步骤 | 仍欠缺的环节 |
|---|---|---|
| [M0038](notes/M0038.md) 第 1 阶段 | 厚度积分、Leibniz 上下限项 | 法向热流符号、闭合假设与变物性平均误差 |
| [M0174](notes/M0174.md) 第 IV、VIII 节；[M0175](notes/M0175.md) 第 2–3 页 | E/F/G、轴对称曲面算子、一面平坦时 H 与中面关系 | 从轴向厚度到法向薄壳厚度的协调；一般曲面算子到标量 Lambda 的条件 |
| [M0053](notes/M0053.md) 第 1–3 节 | 半厚度串联热阻、无量纲阻力之和 | 接触参数来源与代表性；平均温度如何代表界面温度 |
| [M0038](notes/M0038.md) 第 3 阶段 | 抛物线解形式及 1/3 阻力建议 | 完整边界条件、积分常数、平均关系的省略项和误差 |
| [M0054](notes/M0054.md)、[M0038](notes/M0038.md) 第 4 阶段 | 弧长微元、面通量乘 w | 真实接触带面积和两域求积核一致性 |
| [M0037](notes/M0037.md) | 固定热流快照与一致性损失方案 | 没有固定点收敛或普遍防漂移证明；方案中“绝对守恒”需单独检查 |

[M0039](notes/M0039.md) 末尾说 H→0 时 h_eff→∞，但同一文档公式还保留有限的肋半厚度阻力。这个极限陈述不能由其公式直接得到。[M0031](notes/M0031.md) 的通用表面能流写法在上下表面流出符号上也有歧义，不能照录后宣称完整守恒。

## 与软件验证分开阅读

[R122](../verification/records/R122_reference_checks/verification.json) 记录来源迁移与计算检查；[R118](../verification/records/R118_delivery_checks/verification.json) 等运行记录短流程、保存重载和绘图。历史加热/冷却包及本地四个优选版本保持独立。

同权重预测一致和残差兼容支持“按选定来源重写”的判断，不证明选定来源的几何近似正确。短训的温度误差较大，也不能据此反推长训方法无效或某个物理假设正确。历史 `hypotheses.csv` 中的 supported/inconclusive 状态保留为历史登记，本轮没有重新确认。
